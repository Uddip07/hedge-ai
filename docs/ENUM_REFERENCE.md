# Domain Enum Reference Manual

This TDD documentation details the canonical **Domain Enums** implemented in `packages/domain/enums/` for the **Indian AI Hedge Fund** platform.

Every enum inherits from `enum.StrEnum` (Python 3.11+ / 3.12), ensuring string compatibility, JSON serialization, strong type safety, and zero external infrastructure dependencies.

---

## Catalog of Domain Enums

### 1. Market Domain (`packages/domain/enums/market.py`)

| Enum Name | Key Members | Description & Usage Context |
|---|---|---|
| **`ExchangeType`** | `NSE`, `BSE`, `MCX`, `NSDL`, `CDSL`, `NYSE`, `NASDAQ` | Identifies financial exchanges and depositories. Focus on Indian stock & commodity venues. |
| **`MarketSegment`** | `LARGE_CAP`, `MID_CAP`, `SMALL_CAP`, `CASH`, `DERIVATIVES` | Asset market capitalization and trading segment classification. |
| **`MarketStatus`** | `PRE_OPEN`, `OPEN`, `POST_CLOSE`, `CLOSED`, `HALTED` | Operational trading state of an exchange or symbol. |
| **`SettlementType`** | `T_PLUS_0`, `T_PLUS_1`, `T_PLUS_2`, `SAME_DAY` | Trade settlement cycle protocol (e.g. Indian market T+1 equity standard). |
| **`SettlementStatus`** | `PENDING`, `SETTLED`, `FAILED`, `PARTIALLY_SETTLED` | Security & cash clearing and settlement lifecycle state. |
| **`MarketSession`** | `PRE_MARKET`, `NORMAL`, `POST_MARKET`, `BLOCK_DEAL` | Intraday trading session windows. |
| **`Timeframe`** | `TICK`, `1M`, `5M`, `15M`, `1H`, `1D`, `1W`, `1MN` | OHLCV bar aggregation timeframes for technical analysis and backtesting. |
